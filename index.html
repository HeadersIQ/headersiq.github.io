🚀 HeadersIQ Code Runner is now available

The latest HeadersIQ prototype can now be accessed directly through a web browser. The Code Runner provides an interactive way to submit data, execute the header-centric analysis, inspect the inferred semantic formats, and review the resulting Data Quality Assessment outputs without installing the application locally.

The service is currently provided as a research prototype for demonstration and evaluation.
